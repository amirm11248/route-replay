# Clean Launch

A reusable dark premium launch style: pearl surfaces, charcoal typography, deep navy objects, slate light, smoked violet edges. The current demo uses bouncy springs, squash/stretch, a growing opening headline and a landing bounce.

- `kit.js`: drawing helpers and STYLE hooks.
- `STYLE.md`: palette, motion rules, measurements, limits and checklist.
- `sample.png`: full-size reveal frame.
- `demo/index.html`: self-contained, editable browser preview with synthesized sound. Click the canvas to hear it.
- `demo/renders/final.mp4`: full 1080p master.
- `demo/renders/share.mp4`: smaller sharing encode.

Copy `demo/` into `pieces/<your-name>/`, edit its `src/` files, then use the animate build/export tools. Keep `"style": "clean-launch"` in `piece.json`; the tools locate the project style automatically. All typography, panels, lighting and sound are procedural. Other aspect ratios need their own layout.

The original reviewed piece and its render contact sheets are in `pieces/clean-launch-study/`. The demo is an abstract style demonstration, with no product UI or source film media.
