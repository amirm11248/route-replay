# Clean Sketch

Experimental combination of Clean Launch and Sketchbook: deep navy objects, clean spring motion, handwritten emphasis, graphite outlines, paper grain, notebook binding and pencil hatching.

- `STYLE.md`: palette, hybrid choices and composition rules.
- `kit.js`: one merged procedural drawing kit.
- `sample.png`: full-size reveal frame.
- `demo/index.html`: self-contained browser preview. Click the canvas for sound.
- `demo/renders/final.mp4`: full 1080p master.
- `demo/renders/share.mp4`: smaller sharing encode.

Use `"style": "clean-sketch"` in a piece's `piece.json`. Copy the editable `demo/` to start another animation. The original Clean Launch style is available next to this folder.
