# Third-party notices

**Audit date:** 2026-10-11

The iOS app target has no vendored third-party runtime libraries. The optional
`web-motion/` workspace is a separate npm project; its exact packages and
resolved versions are recorded in `web-motion/package.json` and
`web-motion/package-lock.json`. It includes one React Bits component installed
as editable source code.

## Route Replay license boundary

The intended MIT license will apply only to original Route Replay source code
and original assets that the copyright holder is entitled to license. It will
not license Apple's SDKs, Apple Maps content, HealthKit data, or any other
third-party material. A top-level `LICENSE` file still needs to be added with
the correct copyright holder before publication.

- [XcodeGen](https://github.com/yonaskolb/XcodeGen) is an optional build-time

## New York example route data

`RouteReplay/Models/NewYorkReservoirRoute.swift` contains the coordinates of
[OpenStreetMap way 179679714](https://www.openstreetmap.org/way/179679714),
version 15, retrieved on 2026-10-11: the Stephanie and Fred Shuman Reservoir
Running Track. The original vertex order forms a counterclockwise closed loop.
The app interpolates only along those segments for replay.

This coordinate dataset is **© OpenStreetMap contributors**, made available
under the [Open Database License (ODbL) 1.0](https://opendatacommons.org/licenses/odbl/1-0/).
Its contents are subject to the [Database Contents License](https://opendatacommons.org/licenses/dbcl/1-0/).
The coordinates remain under these terms and are excluded from the intended
MIT license for original application code. The source file provides the full
coordinate dataset; preserve its source and attribution when redistributing.
The New York detail screen also links to [OpenStreetMap's copyright notice](https://www.openstreetmap.org/copyright).

The [Central Park Conservancy running guide](https://www.centralparknyc.org/activities/guides/running)
and [running map](https://www.centralparknyc.org/downloadable-running-map)
were used to verify the route's use, official distance, and counterclockwise
direction. Their artwork is not copied into the app.
