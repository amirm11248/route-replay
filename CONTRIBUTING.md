# Contributing

This is a personal hobby project. Use repository issues for bug reports and
small improvement proposals. Include reproduction steps, the relevant iOS
version, and a description using example workouts. Support is provided as time
allows.

Keep real HealthKit records, personal routes, credentials, signing files, and
device logs containing personal information out of issues and pull requests.
See [SECURITY.md](SECURITY.md) for security reports.

Submit only work you have the right to contribute. Original contributions are
licensed under the repository's [MIT License](LICENSE). Identify third-party
code or assets and preserve their required notices and licenses. See
[THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).
