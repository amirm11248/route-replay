# Security policy

Route Replay is a local iOS sample project with no Route Replay server,
accounts, or production API credentials in this repository.

Please do not open a public issue containing HealthKit data, GPS coordinates,
passwords, tokens, certificates, private keys, or debug files from a real
workout.

If the repository is published, use GitHub's private vulnerability reporting
feature (or a private maintainer contact made available in the repository) for
security reports. Include the affected file, reproduction steps, and a safe
sanitized description. Rotate any credential before discussing an exposure.
